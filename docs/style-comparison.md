## 1. 颤音(唱法)

### 旧版

**颤音**(vibrato)是长音上**音高均匀、小幅地起伏**,让声音听起来温暖、有"活"的气息,是唱功成熟的标志之一。

#### 颤音 vs 喉抖(关键区别)

- **真颤音**:气息稳定、喉部放松,音高均匀摆动,像"水波";
- **喉抖/羊声**:喉咙肌肉紧张痉挛造成的抖动,不均匀、发紧——这是要**消除**的毛病,不是技巧。

#### 形成颤音的条件

1. **气息稳**:颤音建立在稳定的气息支撑上——气不稳,抖不起来。
2. **喉部松**:喉部越放松,摆动越自然;用力卡喉咙只会变僵。
3. **音准稳**:颤音是围绕一个准确音高的摆动,音都不准就无从谈起。

#### 练习路径

- 先唱**平稳的长音**(不抖),练气息的"平";
- 再做**慢速两音交替**(如 C–B,一拍一次),把交替逐渐加快;
- 当交替快到一定程度、且喉部放松时,它会自然"连成"颤音。
- 常见误区:用手推肚子/抖下巴"造"颤音——那都是假抖,先别学。

#### 什么时候用

长音、句尾、情感高点用颤音;短促的字、快节奏段落用直声。**颤音是调料,不是主菜**——用太多反而腻。

> 颤音是"练出来"的水到渠成:气息、放松、音准三者到位,它自己会出现。

延伸:基础功是 气息与发声 和 真假声与混声。

### 新版

多数人以为颤音是"抖"出来的。方向反了——颤音不是做出来的动作,是两件事做到位之后的结果:气息稳,喉咙松。

#### 颤音是什么

长音上,音高围绕一个准确的音**均匀地**上下摆动,速度大约每秒 5–7 次,幅度在半音以内。太快听起来是发抖,太宽听起来是跑调。听歌时留意歌手的长音:成熟的颤音是缓慢、均匀的波,不是高频抖动。

#### 两种"抖"

要区分两种抖:

- **颤音**:放松之后出现,均匀,围绕准音摆动;
- 喉抖:喉部肌肉痉挛,不均匀、发紧。这是要修的毛病,不是技巧。

分辨办法很简单:录下来听。喉抖"痉挛、失控",颤音"波浪、稳"。

#### 练习顺序

1. 先练直音。一个音稳住 5 秒不抖——这是气息的及格线。
2. 两个音交替。C 和 B 各唱一拍,逐渐加快。快到某个点、喉咙又放松时,交替会自己"融化"成颤音。
3. 不要从"模仿颤音"开始。推肚子、抖下巴、压喉——造出来的抖是假的,练成习惯很难改。

#### 什么时候用

长音、句尾、情绪高点用颤音;短音、快节奏用直声。句句都颤的人听着腻:颤音是调料,不是主菜。

基础在 气息与发声;放松的感觉和 真假声与混声 相关。

**主要差异**:开头从定义改为先破误解;去掉"像水波"这类比喻堆叠,补了 5–7Hz、半音以内等可核实的量;删掉结尾金句框;"延伸"句式揉进正文。

## 2. 古筝(乐器)

### 旧版

**古筝**是中国最古老的弹拨乐器之一,有两千多年历史,因历史悠久也称"汉筝"。它是国风音乐里最具代表性的音色之一。

#### 基本构造

- 现代标准古筝有 **21 根弦**,按音高从低到高排列,弦下各有一个可移动的**雁柱**(琴码),移柱可以调音。
- 传统定弦是**五声音阶**(宫商角徵羽,即 do–re–mi–sol–la),所以随便拨几个弦都不难听——这正是古筝"易上手"的原因。
- **绿色弦**是"地标":传统上绿弦(有的筝是红弦)代表 **sol**,帮助演奏者快速定位。

#### 演奏方式:右手弹、左手韵

- **右手**戴义甲弹弦:托、抹、勾、打等基本指法,负责发出声音;
- **左手**在琴码左侧**按弦**:通过按压改变音高,做出滑音、颤音、韵味——"左手功夫"是古筝好不好听的关键。
- 高级技法:摇指(长音连绵不断)、刮奏(行云流水的扫弦感)。

#### 代表作品

- 《高山流水》《渔舟唱晚》《寒鸦戏水》等;现代也有大量流行曲的古筝改编。

> 古筝的哲学是"**右手弹声,左手弹韵**":弹出来的音只是骨架,左手按出来的韵味才是血肉。

延伸:五声音阶的乐理见 音阶;中文歌曲常用 简谱 记录。

### 新版

听过《渔舟唱晚》,就听过古筝。它是中国最有代表性的弹拨乐器,入门门槛比多数人想象的低。

#### 先看构造

现代古筝 21 根弦,每根弦下立着一个可以移动的琴码,叫**雁柱**——挪动雁柱就能调音。标准定弦是 D 调五声音阶:每根弦是 do、re、mi、sol、la 之一(见 音阶),没有 fa 和 si,所以随手拨一组弦很难难听。

染成绿色的弦是定位标志,传统上代表 sol。

#### 右手弹声,左手弹韵

右手戴义甲弹弦,基本指法是托、抹、勾。左手在雁柱左侧按弦,改变音高,做出上滑、下滑、吟音——同一根弦同一个音,左手手法不同,味道完全不同。

两个该知道的进阶技法:

- **摇指**:密集地拨一根弦,把点连成线,古筝的"长音"靠它,《高山流水》大量使用;
- 刮奏:一抹扫过一串弦,古筝最有戏剧性的音效。

#### 为什么适合入门

民乐里古筝最"所见即所得":拨哪根弦响哪个音,音准不靠耳朵。很多人练一个周末能弹出《沧海一声笑》。对照 二胡:没有品、没有指板可倚,音准全靠耳朵从零建立——门槛是另一个量级。

五声音阶的乐理在 音阶;古筝谱常用 简谱;现代编曲里它常出现在 国风 作品里。

**主要差异**:开头用《渔舟唱晚》唤起具体听感;补了 D 调、"一个周末弹出《沧海一声笑》"等具体信息;用和二胡的横向对比替代孤立的描述;删掉金句框,"延伸"揉进正文。

## 3. 挂留与加音和弦(和声)

### 旧版

和弦的"性格"来自三度(大或小),而**挂留**与**加音**是在此基础上最常用的两种"加工"。

#### 挂留和弦(sus)

把三度音**替换**成其他音,和弦就"悬"起来,失去大小调的明确性格:

- **sus4**:三度换成四度(如 Csus4 = C F G)——有"想解决回原位"的倾向;
- **sus2**:三度换成二度(如 Csus2 = C D G)——更空、更朦胧。

用法:摇滚/流行里常见 Isus4 → I 的解决(副歌前制造推进力);民谣、新世纪音乐里 sus2 直接当稳定音色用。

[ChordPlayer: Csus4 → C(悬而未决 → 落地) / 四度音滑回三度的经典解决]

#### 加音和弦(add)

三度**保留**,再"添加"一个色彩音(不动七音):

- **add9**:加二度/九度(Cadd9 = C E G D)——温暖明亮,流行吉他最爱;
- **add11 / add13**:四度/六度色彩的点缀。

与七和弦的区别:**七和弦必须带七音,add 和弦不带**——add 更轻盈,没有"急着解决"的倾向。

[ChordPlayer: Cadd9(流行的「光泽感」) / C 与 Cadd9 对比:后者多一层温暖的光]

> 经验:写流行歌时,把普通三和弦顺手换成 sus2 / add9,质感立刻"高级"一档。

延伸:这些标记怎么写见 和弦标记;七和弦的完整体系见 七和弦。

### 新版

听歌时偶尔会遇到一个和弦,"悬"在半空,不亮也不暗,一拍之后落回实处——那就是挂留和弦在解决。

#### sus:把三度换掉

三和弦的大/小性格由三度决定。sus4 **把三度换成四度**:C–E–G 变成 C–F–G,四度和根音打架,耳朵等着 F 落回 E。悬置、解决,"suspended"由此得名。摇滚和流行爱在副歌前来一组,制造推进力。

[ChordPlayer: Csus4 → C / 四度落回三度,那种「落地」就是解决]

sus2 是另一个方向:三度换成二度(C–D–G),不紧张也不解决,只剩开阔、中性的颜色。民谣和后摇里很常见。

#### add:叠一个色彩音

add9 **保留三度**,再往上叠一个九度:C–E–G 加一个 D。性格清楚,又多一层透亮。流行吉他伴奏里 add9、add11 满地都是,因为升级成本极低——把手上的 C 换成 Cadd9,别的什么都不用改:

[ChordPlayer: C vs Cadd9 / 只多一个 D,质感立刻不同]

别和七和弦搞混:add 加的是色彩音,不含七音;七和弦的七音恰恰是为了制造解决冲动(见 七和弦)。想要"有点不一样,但别太多",选 add。

记法(sus4、add9 怎么写)见 和弦标记。

**主要差异**:开头从一个具体的听感场景进入,而不是先给定义;"四度和根音打架,耳朵等着 F 落回 E"这类表达把乐理机制讲得更直观;删掉金句框,"延伸"揉进正文;ChordPlayer 两个组件原样保留。
