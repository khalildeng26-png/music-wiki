# 词条写作风格规则(增量记录)

> 用法:用户指出一处,记录一条;写新内容与修订旧内容时对照本表执行。
> 与 thickening-standard.md 的「二、文风约束」「七、写作层约束 v1.2」并行生效。
> 起因:2026-09-14 灵魂乐样板的三条批评。

## 规则

### R1 标题不自我说明(2026-09-14)

标题只命名内容,不解释写作意图。反例:「核心特征:每一条都有来路」——这是在向读者宣布"我写得很讲究",读者要的是内容本身。正例:「核心特征」。

### R2 术语直述,慎用比喻(2026-09-14)

概念解释以直述为主;比喻仅在直述讲不清时使用,且每节至多一处、必须承载信息。专业术语(如 walking bass)首次出现必须就地定义或链接到词条,不得用未解释的私设说法替代。反例:「贝斯也从行走变成短句」——"行走"是术语没定义,"短句"是私设比喻,读者两边都接不住。正例:「贝斯不再一拍一音地走满(walking bass),改弹短促、重复的音型(riff)」。

### R3 禁用「陈述——抽象总结」句式(2026-09-14)

破折号后接一句金句式收束(「……——同一速度,军鼓每一记都像在推人一把」)是模板化痕迹;一段至多一处破折号,且只用于真正的补充说明。收尾想强调时,用可验证的具体事实替代抽象总结。
