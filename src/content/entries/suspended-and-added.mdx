[和弦](/entries/chord)的"性格"来自三度(大或小),而**挂留**与**加音**是在此基础上最常用的两种"加工"。

## 挂留和弦(sus)

把三度音**替换**成其他音,和弦就"悬"起来,失去大小调的明确性格:

- **sus4**:三度换成四度(如 Csus4 = C F G),有"想解决回原位"的倾向;
- **sus2**:三度换成二度(如 Csus2 = C D G),更空、更朦胧。

用法:[摇滚](/entries/rock)/[流行](/entries/pop)里常见 **Isus4 → I** 的解决(副歌前制造推进力);[民谣](/entries/folk)、[新世纪](/entries/new-age)音乐里 sus2 直接当稳定音色用。

## 加音和弦(add)

三度**保留**,再"添加"一个色彩音(不动七音):

- **add9**:加二度/九度(Cadd9 = C E G D),温暖明亮,流行[吉他](/entries/guitar)最爱;
- **add11 / add13**:四度/六度色彩的点缀。

与七和弦的区别:**七和弦必须带七音,add 和弦不带**:add 更轻盈,没有"急着解决"的倾向。

## 简史:从装饰到材料

"suspension"一词的本意是延留:复调时代,一个声部把上一和弦的音延续到新和弦里,与新的音短暂碰撞,再级进解决。不协和是过程,解决是目的。[古典](/entries/classical)写作中,挂留四度解决回三度至今是终止处的常用手法。到了摇滚与流行时代,吉他手发现 sus 和弦空着三度、色彩中性,干脆让它停在原地不解决;sus2 也从"待解决的音"升格为独立的稳定音色。加音和弦的流行化与吉他关系密切:许多 sus / add 指法依赖空弦的共鸣,听感明亮,于是被写进了和弦标记。悬停不解决的 sus 后来又从吉他扩散进[钢琴](/entries/piano)与铺底音色的写作,成为许多影视开场与转场的标准氛围音。

## 常见误区

1. sus 和弦必须解决:那是传统用法;现代语境里,不解决的 sus 才是常态。
2. add9 就是 sus2 换个写法:sus2 删掉三度,add9 保留三度,听感与功能都不同。
3. 看到 9、11、13 就以为是"[爵士](/entries/jazz)复杂和弦":add 系列不带七音,只是三和弦的色彩点缀,比七和弦更轻。
4. Csus4 里的 4 是小四度:sus4 的四度是纯四度(如 C 上的 F),与大小调无关。

## 名曲用例

- 披头士《A Hard Day's Night》开头的标志性音响,核心就是一个悬而未决的挂留色彩。
- 民谣与新世纪风格的吉他编配常把 sus2 当作稳定音色,整段都停在同一片悬浮的色彩上。
- 许多电影配乐的"史诗感"收尾,是 sus 和弦不解决直接淡出的效果。

## 练习

1. 替换实验:弹一段只用三和弦的伴奏,把其中若干换为 sus2 / add9,对比前后质感。自查:能说出每个替换点带来的变化。
2. 解决与不解决:分别弹 Csus4 → C 与 Csus4 停留两拍,感受"落地"与"悬停"两种效果。自查:不看标记能分辨哪一次解决了。
3. 听感对照:弹 Csus2 与 Cadd9,各停留两拍。自查:能说出前者更空、后者更暖的原因(三度在不在)。

> 经验:写流行歌时,把普通三和弦顺手换成 sus2 / add9,质感立刻"高级"一档。
