[和弦](/entries/chord)的"性格"来自三度(大或小),而**挂留**与**加音**是在此基础上最常用的两种"加工"。

## 挂留和弦(sus)

把三度音**替换**成其他音,和弦就"悬"起来,失去大小调的明确性格:

- **sus4**:三度换成四度(如 Csus4 = C F G)——有"想解决回原位"的倾向;
- **sus2**:三度换成二度(如 Csus2 = C D G)——更空、更朦胧。

用法:摇滚/流行里常见 **Isus4 → I** 的解决(副歌前制造推进力);民谣、新世纪音乐里 sus2 直接当稳定音色用。

## 加音和弦(add)

三度**保留**,再"添加"一个色彩音(不动七音):

- **add9**:加二度/九度(Cadd9 = C E G D)——温暖明亮,流行吉他最爱;
- **add11 / add13**:四度/六度色彩的点缀。

与七和弦的区别:**七和弦必须带七音,add 和弦不带**——add 更轻盈,没有"急着解决"的倾向。
