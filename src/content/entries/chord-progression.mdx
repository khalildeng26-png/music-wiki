**和弦进行**(chord progression)是把多个和弦按顺序连接起来。它就像和声的"句子",决定了音乐的运动方向与情绪起伏。

## 罗马数字标记

在一个调里,每个音级上的和弦用罗马数字表示。以 C 大调为例:

- **I** = C(主和弦,最稳定,home)
- **V** = G(属和弦,强烈倾向回到 I)
- **vi** = Am(下主和弦,色彩柔和)

## 经典进行:I–V–vi–IV

流行音乐里最经典的四个和弦循环就是 **I–V–vi–IV**(C 大调里即 C–G–Am–F)。无数流行金曲都用过这套进行,因为它既顺耳又有情绪推动。

## 张力与解决

好的和弦进行靠**张力 → 解决**制造动力:V(属和弦)制造"想回家"的张力,回到 I(主和弦)就"解决"了,听感上松一口气。

## 根音运动的语法

撇开功能和声的标签,进行的强弱可以直接从**相邻两个和弦根音的音程**读出来(共性写作时期总结的倾向排序,流行依然大体遵守):

- **下行纯五度**(如 G → C):最强推进,五度圈引力的方向,见 [五度圈](/entries/circle-of-fifths) 的「引力引擎」一节;
- **上行二度**(如 F → G):次强,「抬升」的推进感,常出现在推向高潮的路上;
- **下行三度**(如 C → Am):色彩性连接,松弛、温柔,不制造推进;
- **上行五度 / 上行三度 / 下行二度**:连接最弱,除非声部有特别安排,听感容易"卡住"。

用这把尺子复查经典进行:4536251 的后半(3–6–2–5–1)是一串纯下行五度,I–V–vi–IV 里的 V→vi、vi→IV 是上二接下三——顺耳不是玄学,是根音在走强运动。反过来,I→V 的上行五度按间隔算并不“强”,但它是从主功能主动走向属功能、制造张力的方向——间隔尺与功能尺合起来,才是完整的判断。

## 同功能组:进行的另一层自由度

调内七个和弦按功能分成三组:主功能组 I、vi、iii,下属组 IV、ii,属组 V(及 vii°)。**同组之内可以互相顶替**,进行的功能骨架不变——这正是大量"变体进行"的来历:I–V–vi–IV 与 I–V–iii–vi、vi–IV–I–V 骨架同源;4536251 用 iii 顶替主功能、用 ii 顶替下属,把一句 S–D–T 拉长成七步。学会看功能骨架,就能把听过的几十条进行收敛成几句话。

## 和声节奏:被忽视的第三维度

除了「选哪些和弦」和「什么顺序」,还有「**多久换一个**」——和声节奏(harmonic rhythm)。同样的四个和弦,两拍一换是推进、一小节一换是舒展、两小节一换是史诗;不少"高级感"其实来自和声节奏的疏密设计而非和弦本身复杂。把和弦密度当成编曲参数来调度,是写歌进阶的分水岭之一。

## 简史:从终止式到循环

早期的和声进行服务于终止式:音乐的目标是把句子"收住",进行只是通往句点的路线。古典时期,奏鸣曲式的展开部开始把几个和弦的循环当作发展的材料,进行本身获得了结构意义。爵士时代确立了 ii–V–I 这条五度下行的骨架,无数标准曲都建立在它之上。进入流行时代,四小节的和弦循环成为标准段落单位,进行贯穿全曲反复使用,从"通往终点的路线"变成了贯穿始终的结构成分。

## 常见误区

1. 和弦必须按 I–IV–V 的"正路"连接:规则描述的是常见倾向,不是禁令;意外连接正是创作空间所在。
2. 换个调,罗马数字也要换:数字标记的好处恰恰是跨调通用:在 G 大调里, I–V–vi–IV 对应的是 G、D、Em、C,级数关系不变。
3. 进行里每个和弦都要弹满整小节:和弦的切换密度可以变化,半拍换一个和弦的推进感完全不同。
4. 高级进行一定比循环好:大量名曲终生只用一套循环,起伏来自旋律、编曲与力度,而非和弦的复杂程度。

## 名曲用例

- 披头士《Let It Be》主歌使用 I–V–vi–IV 的变体,是这套进行的教科书级示范。
- 五十年代大量金曲共享 I–vi–IV–V 循环,后来的许多流行歌仍在沿用。
- 卡农式低音进行(帕赫贝尔《D 大调卡农》的套路)衍生出无数流行与说唱伴奏。
- 大量华语抒情歌的副歌从 vi 或 IV 起步,绕一圈后停在 I 上——进行没换,情绪的落点全靠段落安排。

## 练习

1. 级数背诵:在 C、G、F 三个大调上,分别写出 I、IV、V、vi 对应的和弦名。自查:任意说一个调与级数,能立刻弹出。
2. 循环弹唱:选 I–V–vi–IV,节拍器 70–90 BPM,每小节换一次和弦。自查:换和弦时不抢拍、不中断节奏。
3. 换调迁移:同一套进行移到 G 大调再弹一遍。自查:指法变了,但进行的功能感与在 C 大调时一致。

> 写歌、配伴奏时,选对和弦进行,情绪就对了一大半。
