**调式**(mode)指一组音中各音的**主次关系**:哪个音是"主音"(home),其余音围绕它构成张力与解决。**调性**(key)则是这组音整体的**音高位置**。

## 大调与小调

最常用的两种调式:

- **大调**:主音到三音是大三度,色彩**明亮**(如 C 大调)。
- **小调**:主音到三音是小三度,色彩**柔和、忧郁**(如 a 小调)。

C 大调与 a 小调用的是**同样的七个白键音**,但主音不同,听起来情绪完全不一样,这就是调式的力量。

## 调号

五线谱开头的一堆升号 ♯ 或降号 ♭ 叫**调号**,标明了这首曲子的调性。例如:无升降 = C 大调 / a 小调;一个 ♯ = G 大调 / e 小调。

## 关系调与同主音调:两套容易混的「亲戚」

- **关系大小调**(relative):共用同一套音与调号,如 C 大调 ↔ a 小调:省事但情绪两样,上文已听过;
- **同主音大小调**(parallel):主音相同、调号不同,如 C 大调 ↔ c 小调(三个降号)。同主音对比更「狠」:家的位置不动,只换明暗,所以配乐爱用它一键切换情绪;[借用和弦](/entries/borrowed-chords)的机制(大调歌里突然出现小调的和弦),本质就是短暂借用同主音小调的色彩。

## 调性中心是怎么立起来的

「以某音为家」不是一句话,是几条线索的合力:终止式落在 V–I(和声上关门)、旋律末句回到主音(旋律上点名)、和声按 T–S–D 的功能序进绕主和弦展开、开头结尾用长音或持续音钉住主音。反过来,想写「漂浮、无家」的音乐,就把这些线索逐条抽掉:避开 V–I、少给终止、和声平行走。德彪西与不少影视配乐正是这么做出「悬在半空」的效果。听音乐时问一句「家立住了吗、靠什么立的」,判断力会立刻变锐。

## 转调

音乐中途改变调性叫**转调**,常用来推高情绪或制造层次变化。

## 历史:大小调是怎么坐上主位的

今天的大小调体系不是自古就有的。中世纪欧洲的音乐以教会调式为基础,大调与小调只是其中两个成员;几个世纪里,其余调式逐渐退居幕后,大小调成为主流。18 世纪初,法国作曲家拉莫在《和声学》中为大小调的和声逻辑建立了理论框架;几乎同一时期,巴赫的《平均律钢琴曲集》走遍了全部 24 个大小调,用作品宣告这套体系已经成熟。此后三百年的绝大多数流行、古典音乐,都在这个体系里写就。

## 名曲用例

- 贝多芬《第五交响曲》:开头"命运敲门"的动机在 c 小调上,小调的紧张感从第一个音就立住了。
- 大量流行歌的最后一遍副歌整体升半音:这是移调,不是转调:旋律原样,整个调性抬高一级,情绪顺势推上去。
- 《欢乐颂》的主题从 3 音起,完整主题最终落回主音 1:主音一出现,"家"的感觉立刻确立,是练习找主音的好材料。

## 常见误区

1. 大调一定开心、小调一定悲伤。主音到三音的距离决定基本底色,但速度、织体、音区都会改写情绪:慢的大调可以忧伤,快的小调可以亢奋。
2. 关系大小调是同一个调。它们共用调号与音,但主音不同:一首曲子停在 A 上、以 A 为家,就是 a 小调,不能叫 C 大调。
3. 换调就是转调。整首歌整体移高半音是移调,旋律关系不变;转调指曲子进行到中途,调性中心发生切换。
4. 调号能直接告诉你大调还是小调。调号只给出一对候选,最终看主音停在哪、哪个和弦有"家"的感觉。

## 练习

1. 找主音:选三首熟悉的歌,哼出每首结尾停住的长音,判断它是不是全曲最稳定的音。自查:三首里至少两首能稳定哼准这个音。
2. 判大小:只凭开头几秒判断一首歌是大调还是小调,再用主音到三音的距离核对。自查:连续五首正确率不低于四首。
3. 关系调改写:把一段 C 大调旋律整体移到 A 起、全用白键弹,听它变成什么情绪。自查:能说出移前后情绪的差异,并指出主音变了、音集没变。

> 调式决定明暗情绪,调性决定整体高低。
