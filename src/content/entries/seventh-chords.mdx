**七和弦**是在[三和弦](/entries/chord)之上**再叠一个三度**得到的四音和弦。因为多了一个"七音",色彩更复杂、更"有味道",是流行、R&B、爵士的基本材料。

## 三种最常用的七和弦(以 C 为根音)

| 名称         | 构成              | 记号        | 色彩                     |
| ------------ | ----------------- | ----------- | ------------------------ |
| **大七和弦** | 大三和弦 + 大三度 | Cmaj7 / C△7 | 明亮而梦幻、柔和         |
| **属七和弦** | 大三和弦 + 小三度 | C7          | 不稳定、"想解决"的张力感 |
| **小七和弦** | 小三和弦 + 小三度 | Cm7         | 柔和、慵懒、爵士味       |

## 为什么属七和弦特殊

在自然音阶里,**只有第五级(V 级)上**天然形成属七和弦。它内部包含一个**三全音**(增四度)——最"不安"的音程,因此属七和弦天然渴望**解决到主和弦**,这正是[终止式](/entries/cadences)的动力来源。

> 记忆法:三和弦是"三块积木",七和弦是"四块积木"——多出来的那块,决定了它是梦幻(大七)、紧张(属七)还是慵懒(小七)。
