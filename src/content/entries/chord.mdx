**和弦**(chord)是三个或更多音**同时发声**的组合。最基本的是**三和弦**——三个音按**三度**叠置:根音、三音、五音。

## 大三和弦与小三和弦

- **大三和弦**:根音到三音是大三度,三音到五音是小三度。如 C 大三和弦 = C–E–G,色彩**明亮**。
- **小三和弦**:根音到三音是小三度,三音到五音是大三度。如 C 小三和弦 = C–E♭–G,色彩**柔和**。

## 其他常见三和弦

- **增三和弦**:两个大三度叠置,紧张、悬浮。
- **减三和弦**:两个小三度叠置,刺耳、不稳定。

在 C 大调里,主和弦(C)、下属和弦(F)、属和弦(G)合称正三和弦,它们的循环已经能撑起一首简单的歌:

## 四种三和弦的构成规律

四种三和弦都由"下面一个三度 + 上面一个三度"叠成,记住两个格子各是什么:

| 类型       | 下方三度 | 上方三度 | 示例        |
| ---------- | -------- | -------- | ----------- |
| 大三和弦   | 大三度   | 小三度   | C–E–G       |
| 小三和弦   | 小三度   | 大三度   | C–E♭–G      |
| 增三和弦   | 大三度   | 大三度   | C–E–G♯      |
| 减三和弦   | 小三度   | 小三度   | C–E♭–G♭     |

规律:上下两格对称(大+小、小+大)的是常用和弦,对称同色(大+大、小+小)的是不稳定的增、减和弦。

## 不同乐器上的和弦

同一个和弦,落到不同乐器上形态不同,但构成规则一致:

- 钢琴:双手自由,排列与重复哪个音都可以按需要安排;
- 吉他:六根弦,常用开放和弦会重复某些组成音(如 C、G 的开放指法),爵士类指法则常省略五音;
- 贝斯:通常只弹根音,把完整的和弦留给其他乐器。

## 简史:从音程组合到"和弦"

"和弦"作为理论概念被系统讨论,要从 18 世纪说起。1722 年,法国作曲家拉莫在巴黎出版《和声学》,第一次把三度叠置的和弦当作理论的核心对象,并用"基础低音"统一解释原位与转位:同一组音,无论怎么排列、无论低音落在哪个音上,和弦的身份都由根音决定。在他之前,理论家描述的重点是各声部之间的音程关系,而不是一组同时发声的音本身。从这之后,和声理论的基本单位由音程组合换成了和弦,今天"先认和弦、再谈连接"的学习路径,正是从这里开始的。

## 常见误区

1. 琶音不算和弦——依次弹出的分解形式与同时弹出的组成音完全相同,只是呈现方式不同;伴奏里常见的柱式与琶音用的是同一个和弦。
2. C 和弦必须按 C–E–G 从低到高排列——组成音是 C、E、G 就都是 C 和弦,排列与八度位置可以任意安排;最低音换成和弦里的其他音,就进入 [和弦转位](/entries/chord-inversions)。
3. 大三等于开心、小三等于伤心——实际色彩还受速度、音区与前后和弦影响,慢速、低八度的大三和弦照样可以沉重。
4. 增、减三和弦是用错了音——它们是正常构造,只是不稳定,常被用来制造过渡与紧张感。

## 名曲用例

- 贝多芬《欢乐颂》(第九交响曲末乐章):旋律开头是两个同度反复的音,随后级进上行;整段旋律建立在主和弦与属和弦的交替上,两个三和弦就足够撑起整段。
- 帕赫贝尔《D 大调卡农》:一个低音模式循环到底,上方声部的三和弦随之反复,简单材料搭出了丰富的层次。
- 披头士《Let It Be》主歌前四个和弦 C、G、Am、F 全部是三和弦,推进与抒情兼得。

## 练习

1. 白键三和弦:在 C 大调七个音级上各叠一个三和弦(每隔一个白键取一个音),逐个弹并分辨性质。自查:不看书能说出哪几个是大三、哪几个是小三,以及七级上的减三和弦。
2. 只动一个音:弹 C 大三和弦,把中间的 E 降成 E♭,再弹回来。自查:能向别人解释"三音决定大小"。
3. 听感记录:随机弹 10 个白键三和弦,先凭耳朵猜大小,再看键盘核对。自查:连续 10 个里猜对 8 个以上。
