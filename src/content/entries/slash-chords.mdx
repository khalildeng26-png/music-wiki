**斜杠和弦**(slash chord)的记法是 `和弦/低音`,例如 **C/G** 表示"弹 C 和弦,但最低音用 G"。斜杠右边**独立指定低音**,它可以是和弦内音,也可以是[和弦外音](/entries/non-chord-tones)。

## 最常见的用途:低音线条

[流行](/entries/pop)歌里最经典的用法,是让低音**一步步走下去**:

**C → G/B → Am**(低音 C → B → A 半音下行),副歌前那句"下楼梯"的感觉,就是低音线条在做戏。

## 三种典型情形

1. **转位写法**:C/E、G/B:斜杠音是和弦内音,本质是 [转位](/entries/chord-inversions),只是流行记谱更直白;
2. **低音线条**:如上例,为连贯低音线而存在;
3. **色彩叠加**:低音是**和弦外音**,如 D/F♯、C/D,低音与和弦产生新的张力,常见于 [R&B](/entries/rnb) 与电影配乐。

## 怎么读、怎么弹

- [钢琴](/entries/piano):左手弹斜杠右边的音,右手弹和弦;
- [吉他](/entries/guitar):找对应的低音弦按法(很多和弦图直接标注了斜杠形式);
- 编曲:贝斯手看斜杠右边的音,那就是他该弹的 [根音](/entries/chord)。

## 简史:数字低音的通俗化

巴洛克时期,键盘手按一条低音声部加数字即兴伴奏,转位与非常规低音都靠数字标注,这就是数字低音。流行与[爵士](/entries/jazz)时代,乐手需要拿到谱就能直接弹,于是发明了更直白的斜杠记法:左边写和弦,右边写低音,不用再做[音程](/entries/interval)换算。同一个音响,两种记法,斜杠记法因为"看一眼就知道手往哪放",成了吉他谱与流行乐谱的默认语言。

一个经典样本:披头士《Something》的主歌,让一条半音下行的低音线走在几乎不动的 C 和弦之上(记作 C → C/B → C/B♭……),静止的和声与行走的低音形成对比,斜杠和弦就是为这类写法而生的。

## 常见误区

1. 看到斜杠就当转位处理:只有斜杠音是和弦内音时才是转位;C/D 这类外音低音是独立的色彩,照谱弹低音即可,不要"还原"成原位。
2. 右手可以随便换排列:上方声部的排列可以调整,但最低音必须是指定的那个音,否则效果就没了。
3. 斜杠和弦都是复杂和弦:它们大多就是普通三和弦换了个低音,读法只有两步:先认和弦,再认低音。
4. 斜杠右边可以写成任何音:理论上可以,但常用写法都是出于低音线条或转位的需要;毫无理由的怪低音只会让演奏者多一次困惑。

## 练习

1. 低[音阶](/entries/scale)梯:以 C 大调写一条低音上行或下行的四和弦进行,允许使用斜杠和弦。自查:低音是连续的级进或小跳,没有突兀的大跳。
2. 双手分家:钢琴上右手弹 C 和弦不动,左手依次弹 C、B、A、G 四个低音。自查:能听出和弦没变、低音在走。
3. 读谱速度:找一份带斜杠和弦的吉他谱或流行乐谱,把每个斜杠和弦的"和弦 + 低音"两个信息分别念出来,再看指法核对。自查:十个斜杠和弦里,低音认错不超过一个。

> 斜杠和弦的核心是低音独立:低音不再跟随和弦根音,可以走自己的线,级进、半音或持续音都可以。
