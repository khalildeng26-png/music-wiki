**鼓谱**(drum notation)是[架子鼓](/entries/drums)等打击乐器的专用记谱法。它和旋律谱的最大区别:**不记音高,记"敲哪件乐器"**:谱上的位置对应具体的鼓或镲。

## 谱面基础

- 鼓谱通常用**五线谱的外形**,但谱号换成**打击乐谱号**(两条竖线 𝄪)或干脆不写——因为没有音高概念。
- **圆形符头** = 鼓类;**叉形(x)符头** = 镲类。
- 符杆朝上朝下常用来区分"手"与"脚"声部(脚踩的底鼓、踩镲朝下)。

## 常见位置(标准约定)

| 乐器                    | 谱上位置                    | 符头 |
| ----------------------- | --------------------------- | ---- |
| 底鼓(Kick)              | 最下方(第一线附近/下加一间) | 圆形 |
| 军鼓(Snare)             | 中间(第三间)                | 圆形 |
| 嗵鼓(Toms)              | 底鼓与军鼓之间的线间        | 圆形 |
| 踩镲(Hi-hat)            | 顶部线上方                  | x    |
| 吊镲/叮叮镲(Crash/Ride) | 比踩镲更高的上方            | x    |

> 不同出版社的位置约定略有差异,谱子开头一般会附一张**图例(legend)**:拿到新鼓谱先看图例。

## 常用特殊记号

- **踩镲开合**:x 上方标 `o` = 开镲(open),标 `+` = 闭镲(closed)。
- **重音**:符头上方标 `>`。
- **幽灵音(ghost note)**:极轻的装饰音,用小括号 `( )` 包住符头。
- **滚奏**:符杆上加斜线,表示快速连续击打。

## 简史

- 军鼓的鼓谱有数百年历史,远早于套鼓:军乐中的小军鼓鼓点在 18、19 世纪的欧美鼓手册里已有系统记写。
- 套鼓诞生后,一位乐手要同时操作多件打击乐器,鼓谱随之改为"一个位置对应一件乐器"的多行写法。
- 20 世纪中期起,欧美打击乐界开始推动统一的位置约定,1961 年成立的美国打击乐艺术协会(percussive Arts Society)长期维护一套通行的鼓谱位置表。
- 统一至今没有完全实现:出版社、教材与乐队之间仍有细节差异,这也是图例存在的原因。

## 常见误区

1. 把位置读成音高:符头高低只表示敲哪件乐器,鼓和镲没有旋律意义上的音高,不需要像读 [五线谱](/entries/staff-notation) 那样换算音名。
2. 不看符杆方向:符杆区分手与脚的声部,底鼓声部通常符杆朝下;把所有符头串成一条线读,节奏必错。
3. 拿到谱子直接上手:跳过图例,想当然按自己熟悉的约定读,位置很容易认串。
4. 以为鼓谱的时值另有一套:符尾、符杠、拍号规则与旋律谱完全一致,该练的节奏功一样不少。

## 节奏是核心

鼓谱的时值、拍号规则和旋律谱完全相同(四分、八分、十六分音符),只是"音高"换成了"乐器"。先吃透 [节奏与拍号](/entries/rhythm-and-time-signature),再对照位置表,鼓谱就不难了。

## 练习

1. 单声部读谱:只读踩镲声部的一小节八分音符,节拍器 60 BPM 跟打。自查:每一下都落在拍点或半拍位置上,无赶拍。
2. 声部叠加:先只打底鼓声部,稳了以后叠加军鼓,最后叠加踩镲。自查:三件乐器的进入点都数得清,不打架。
3. 数拍读谱:选一段两小节的鼓谱,边念"1-&-2-&"边打出对应的声部。自查:录音回放,每一下击打都落在正确的位置。
