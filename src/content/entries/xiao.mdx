**箫**(Xiao)是竖吹的竹管乐器,没有笛膜孔,音色**内敛、深沉、轻柔、恬静**。如果说 [笛子](/entries/dizi) 是「明亮外向」,箫就是「沉静内敛」——它更安静,更适合独处和意境。

## 与笛子的区别

|      | 箫               | 笛子             |
| ---- | ---------------- | ---------------- |
| 吹法 | 竖吹             | 横吹             |
| 笛膜 | 无               | 有               |
| 音色 | 内敛、深沉、轻柔 | 脆亮、甜美、明亮 |
| 音量 | 小,但穿透力强    | 较大             |

箫的音量虽然不大,但**穿透力强**,在安静的环境里能传得很远,气质沉静、悠远,常用来表现山水、月夜、思念的意境。

## 构造

- 常见为**六孔**(前面五孔、后面一孔),改良的八孔箫更多音;
- 常见箫筒音为 d1,筒音作徵音,称 **G 调箫**;
- 音色甘美、柔和、深沉,强弱的幅度不大。

> 想分辨箫?找那个「竖吹、没有笛膜的脆亮、更低沉更安静」的竹管声——就是它。

延伸:它的「兄弟」是 [笛子](/entries/dizi);意境上常与 [国风](/entries/guofeng) 音乐相伴。
