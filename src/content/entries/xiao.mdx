**箫**(Xiao)是竖吹的竹管乐器,没有笛膜孔,音色**内敛、深沉、轻柔、恬静**。如果说 [笛子](/entries/dizi) 是「明亮外向」,箫就是「沉静内敛」,它更安静,更适合独处和意境。

## 与笛子的区别

|      | 箫               | 笛子             |
| ---- | ---------------- | ---------------- |
| 吹法 | 竖吹             | 横吹             |
| 笛膜 | 无               | 有               |
| 音色 | 内敛、深沉、轻柔 | 脆亮、甜美、明亮 |
| 音量 | 小,但穿透力强    | 较大             |

箫的音量虽然不大,但**穿透力强**,在安静的环境里能传得很远,气质沉静、悠远,常用来表现山水、月夜、思念的意境。

## 构造

- 常见为**六孔**(前面五孔、后面一孔),改良的八孔箫更多音;
- 常见箫筒音为 d1,筒音作徵音,称 **G 调箫**;
- 音色甘美、柔和、深沉,强弱的幅度不大。

## 简史

- 中国的竖吹管乐器传统极为古老,古籍中的"箫"一词最早指排箫一类编管乐器;单管的竖吹竹管后来逐渐独立成形,"箫"的名称也随之固定到今天的洞箫。
- 唐宋以降,竖吹竹管与琴、棋、书、画一同进入文人生活,箫的"静"与古琴的"淡"气质相投,"琴箫合奏"成为文人雅集里的常见组合,也留下了专门的合奏曲目。
- 明清以来,洞箫的六孔形制与音律逐渐稳定,箫的制作讲究竹材选料与管径调音,一支好箫要"吹得通、立得住、音色匀"。
- 现代常见的八孔箫,是为扩充音域、方便转调而出现的改良形制,在专业演奏与国乐创作中使用渐多。

## 名曲用例

想认识箫,从传统曲目与合奏场合听起:

- 《平沙落雁》:传统曲目,箫的版本取意秋江暮色、雁群起落,长音连绵、气息舒缓,是体会箫之"静"的标准曲目。
- 《阳关三叠》的琴箫合奏版本:古琴与箫一问一答,声部疏朗,听箫在合奏里如何"让"与"托"。
- 影视配乐与国风创作里,箫常承担夜晚、思忆一类的段落:音色一出,画面感即来,这是它在现代编曲里最常见的分工。

## 常见误区

1. 把箫当成"低音笛子"。两者吹法、结构、音色都不同:笛横吹有膜,音色脆亮外放;箫竖吹无膜,内敛深沉,不是笛子降个调。
2. 用力吹出音量。箫的音量天生不大,强弱幅度有限,蛮力只会气声漏气、音色发噪;安静的环境本身就是箫的舞台。
3. 拿笛子的口风去吹箫。竖吹的口风角度与横吹不同,要更缓、更细、更贴边棱,初学者照搬笛子习惯往往久吹不响。
4. 追求"名竹"。入门阶段瓶颈在气息与口风,不在器材;一支调音正常的练习箫足够练很久。

## 练习

1. 长音(每天 15–20 分钟):每个音保持 8–10 秒,音量平稳不晃,从中音区向两端扩展。自查:无忽强忽弱、无明显气声。
2. 气息匀速:吸气后从齿间匀速吐"丝",目标 20 秒以上。自查:长音能稳定撑到 10 秒以上,基本功即算入门。
3. 五声慢练:节拍器 60 BPM,一拍一音吹 G 调五声[音阶](/entries/scale),先上行再下行。自查:每个音出音稳定,不靠蛮力、尾音不掉音高。
4. 录音回听:每周录一段同样的乐句,回放对比口风与气息的变化。自查:音色一周一周变"匀",气声与杂音逐次减少。

> 想分辨箫?找那个「竖吹、没有笛膜的脆亮、更低沉更安静」的竹管声,就是它。

延伸:它的「兄弟」是 [笛子](/entries/dizi);意境上常与 [国风](/entries/guofeng) 音乐相伴。
