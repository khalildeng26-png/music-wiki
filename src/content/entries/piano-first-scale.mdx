    a: 拇指从其他手指下方穿过去够更远的键。没有穿指,一只手一次只能弹五个音;有了它,五个手指就能覆盖整条音阶,这是钢琴指法的第一个核心动作。

C 大调 = 全白键,结构是「全全半全全全半」([音阶](/entries/scale))——E–F 和 B–C 两处天然是半音,所以整条音阶一个黑键都不用碰。它是钢琴的第一条跑道。

## 指法:1-2-3-1-2-3-4-5

右手一个八度上行,C–D–E–F–G–A–B–C 对应 **1-2-3-1-2-3-4-5**。下行原路返回:5-4-3-2-1-3-2-1。

关键在中间那个「1」:3 指弹完 E 之后,拇指从 3 指**下方穿过**去按 F——这就是**穿指**,钢琴指法的第一个核心动作。会了穿指,一条跑道就能跑出比五个手指更远的距离。

## 名曲用例

- 莫扎特《C 大调钢琴奏鸣曲》(K.545)第一乐章:开头的右手主题就建立在 C 大调音阶的音上,两百多年来都是钢琴课堂的第一批教材。
- 哈农与车尔尼的入门练习册,第一条音阶练习都是 C 大调——这条跑道是教材的共识起点,车尔尼 599 的开篇练习同样从 C 大调起步。
- 《欢乐颂》的右手旋律几乎全部落在 C 大调音阶的音上,音阶上下行练顺之后就能直接上手。
- 《小星星》同样全在白键里进行:音阶走顺,它就是你能直接读下来的第一首曲子。

## 练法

- 先单手、极慢,**每个音弹实了再进下一个**;
- 穿指时手腕保持平稳,不拱起——手腕一拱,速度立刻卡住;
- 目标不是快,是**均匀**:每个音的时值和力度尽量一样。

## 常见坑

- **4 指无力**:4 指天生最弱(它的肌腱和 3 指连着),单独多给它几个慢速重复;
- **手型塌陷**:弹着弹着手就平下去。慢下来,回到虚握球的手型([坐姿、手型与指法编号](/entries/piano-posture))。

## 试一试

把节拍器放在 60 BPM,先用耳朵跟拍点:一拍一个音走音阶,先确认每个音都落在拍点上;走顺之后改成每拍两个音,指法不变。下行同样重要:走到顶之后原路返回,拇指提前往掌心方向准备,别等 3 指到了才挪。速度一稳,穿指的问题会自己冒出来——那时再回头慢练那一下。

## 练习

1. 一拍一音报指法:60 BPM,右手上行一个八度,边弹边念出指法编号 1-2-3-1-2-3-4-5。自查:念到第二个"1"时(穿指处)不停顿、不抢拍。
2. 一拍两音:同一速度改成每拍两个音,指法不变。自查:八个音的音量保持在同一水平,第 4 指弹的 F 不发虚。
3. 左手镜像:左手按 5-4-3-2-1-3-2-1 上行,60 BPM。自查:3 指跨过拇指的那一下不带出手腕晃动。
4. 闭眼慢走:闭上眼睛,右手上行走一个八度,让手指自己找键。自查:穿指到 F 的那一下没有落空——这测的是手感记忆,不是眼睛。
5. 边弹边报:回到 60 BPM,右手边弹边念指法或音名。自查:念到第二个"1"(穿指处)不卡壳——嘴和手同时在线,才算真的不用想。

三条都过了,再把节拍器提到 80 BPM 检查一遍:速度上去之后先掉队的,通常就是穿指那一下。

一只手跑顺了,下一关是让两只手一起工作。
