[五度圈](/entries/circle-of-fifths)上**挨着**的调共用最多的音。把"共用"量化:两个调的调号相差**不超过一个升降号**时,互为**近关系调**(closely related keys)。以 C 大调为例,它的近关系调正好五个:

| 近关系调 | 调号 | 与 C 大调的关系 |
| -------- | ---- | --------------- |
| G 大调   | 1♯   | 属方向邻居      |
| F 大调   | 1♭   | 下属方向邻居    |
| a 小调   | 0    | 关系小调        |
| e 小调   | 1♯   | 属调的关系小调  |
| d 小调   | 1♭   | 下属调的关系小调 |

小调同理,按调号距离的严格口径:a 小调(0♯)的近关系调也是五个:C 大调(关系大调)、e 小调与 G 大调(属方向)、d 小调与 F 大调(下属方向)。大小调的差别只在"关系小调"换成了"关系大调",圈上左邻右舍加各自里外圈的逻辑完全一样。

## 为什么"近":共用和弦最多

C 大调的七个自然三和弦(C、Dm、Em、F、G、Am、B°),与 G 大调共用四个(C、Em、G、Am,只差 Dm↔D、F↔Bm、B°↔F♯° 三组),与 F 大调也共用四个;而共用音多达六个(七个音里只差 F 与 F♯),pivot 之所以够用,底牌正是这张共用音清单。**共用[和弦](/entries/chord)就是转调的"pivot"(枢轴)**:先用原调身份出现,再按新调身份解读,调性就悄悄搬家了,[转调](/entries/transposition) 里最顺滑的一种就是借它完成。

## 两个实用结论

1. **想转得顺,往邻居转**:[古典](/entries/classical)时期绝大多数转调停在属调或关系小调,正是因为 pivot 多、痕迹小。
2. **想转得"爽",往远处转**:[流行](/entries/pop)歌副歌升全音(C → D)在五度圈上是两步、升两个调号,不属于近关系,它要的就是那股推力,与近关系转调是两种修辞。

## pivot 三步走

把「共用和弦当枢轴」落成可操作的三步,以 C 大调转 G 大调为例:

1. 让一个共用和弦以旧调身份收尾:比如一句 C 调乐句停在 Am(vi);
2. 紧接着的进行按新调重新解读它:同一个 Am,在 G 调里是 ii,身份悄悄换了;
3. 立刻接新调的 V–I(D → G)落稳,转调完成。之后若在新调停留足够久,耳朵就彻底"搬家"了。

判断成败的标准只有一条:听者回头看时,说不出转调发生在哪一小节。

## 远近的分级

调号距离给了「远近」一把尺子:差 0–1 个调号是近关系(本文主角);差 2 个(如 C ↔ D、C ↔ B♭)算「次近」,流行歌升全音转调就在这档:无痕做不到,但推力可听;差 3 个以上是远关系,转过去需要共同音、等音改写或干脆直接硬切等特殊手法兜底。分级不是鄙视链,只是不同修辞预算:越远越贵,也越响。

## 常见误区

1. 把"近关系"等同于"听起来像":它是调号距离的客观定义,听感相似度还受调式、配器影响。
2. 以为平行大小调(C ↔ c)是近关系:调号差三个,按定义不是;它们走同主音的[调式互换](/entries/borrowed-chords)路线,近得"另类"。
3. 转调必须经过近关系:远关系转调靠共同音、等音或干脆硬切都能成立,近关系只是最省力的路。

## 练习

1. 五秒报邻:随机说一个大调,立刻报出它的五个近关系调。自查:连抽 5 个调不错。
2. 找枢轴:写出 C 大调与 G 大调共用的四个三和弦(C、Em、G、Am),挑一个当 pivot,把一句 C 调旋律无痕送进 G 调。自查:进入新调后能停稳在 G 的终止上。

> 近关系调就是五度圈上的左邻右舍,加各自的关系小调,共五个。转调先从这五个里选,不够再往外看。
