同样的音符,**怎么奏**完全不同——强弱与演奏记号就是谱面上的"表情指示",决定音乐的力度、呼吸与性格。

## 力度记号(Dynamics)

意大利语缩写,写在谱子下方:

| 记号  | 全称        | 含义               |
| ----- | ----------- | ------------------ |
| `pp`  | pianissimo  | 很弱               |
| `p`   | piano       | 弱                 |
| `mp`  | mezzo-piano | 中弱               |
| `mf`  | mezzo-forte | 中强               |
| `f`   | forte       | 强                 |
| `ff`  | fortissimo  | 很强               |
| `sfz` | sforzando   | 突强(单个音的重击) |

## 渐变记号

- **渐强(crescendo)**:`cresc.` 或 **开口向右的尖角** `<`(像喇叭越吹越大)。
- **渐弱(diminuendo / decrescendo)**:`dim.` / `decresc.` 或**开口向左的尖角** `>`。

> 尖角指向的方向 = 音量变化的方向,别记反。

## 常用奏法记号(Articulation)

标在符头上方或下方:

| 记号      | 名称                     | 效果              |
| --------- | ------------------------ | ----------------- |
| `·`(点)   | 断奏(staccato)           | 音奏得短促、分离  |
| `–`(横线) | 保持音(tenuto)           | 音奏满时值,略强调 |
| `>`       | 重音(accent)             | 这个音明显突出    |
| `⌒`(弧线) | 连奏/圆滑线(legato/slur) | 弧内各音连贯不断  |
| `𝄐`       | 延长号(fermata)          | 该音自由延长      |

## 反复与段落记号

- **反复记号** `‖: :‖`:两个竖点之间的小节**重复演奏一遍**。
- **一房子/二房子**(1. 2.):反复时第一次走 1,第二次跳过 1 走 2。
- **D.C.** / **D.S.**:从头反复(Da Capo)/从记号 𝄋 处反复(Segno);配合 **Coda 𝄌** 跳到结尾段。

> 力度与奏法记号是演奏者的"二度创作空间":谱面写 `p`,到底是多轻、轻得多圆润——正是诠释的学问。
