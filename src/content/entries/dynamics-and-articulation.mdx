  - q: 常见的力度记号有哪些?
    a: pp 很弱、p 弱、mp 中弱、mf 中强、f 强、ff 很强、sfz 突强。渐强用 cres. 或开口向右的尖角 <,渐弱用 dim. 或开口向左的尖角 >。

同样的音符,**怎么奏**完全不同——强弱与演奏记号就是谱面上的"表情指示",决定音乐的力度、呼吸与性格。

## 力度记号(Dynamics)

意大利语缩写,写在谱子下方:

| 记号  | 全称        | 含义               |
| ----- | ----------- | ------------------ |
| `pp`  | pianissimo  | 很弱               |
| `p`   | piano       | 弱                 |
| `mp`  | mezzo-piano | 中弱               |
| `mf`  | mezzo-forte | 中强               |
| `f`   | forte       | 强                 |
| `ff`  | fortissimo  | 很强               |
| `sfz` | sforzando   | 突强(单个音的重击) |

## 渐变记号

- **渐强(crescendo)**:`cresc.` 或 **开口向右的尖角** `<`(像喇叭越吹越大)。
- **渐弱(diminuendo / decrescendo)**:`dim.` / `decresc.` 或**开口向左的尖角** `>`。

> 尖角指向的方向 = 音量变化的方向,别记反。

## 常用奏法记号(Articulation)

标在符头上方或下方:

| 记号      | 名称                     | 效果              |
| --------- | ------------------------ | ----------------- |
| `·`(点)   | 断奏(staccato)           | 音奏得短促、分离  |
| `–`(横线) | 保持音(tenuto)           | 音奏满时值,略强调 |
| `>`       | 重音(accent)             | 这个音明显突出    |
| `⌒`(弧线) | 连奏/圆滑线(legato/slur) | 弧内各音连贯不断  |
| `𝄐`       | 延长号(fermata)          | 该音自由延长      |

## 反复与段落记号

- **反复记号** `‖: :‖`:两个竖点之间的小节**重复演奏一遍**。
- **一房子/二房子**(1. 2.):反复时第一次走 1,第二次跳过 1 走 2。
- **D.C.** / **D.S.**:从头反复(Da Capo)/从记号 𝄋 处反复(Segno);配合 **Coda 𝄌** 跳到结尾段。

## 简史

- 文艺复兴的乐谱几乎不标力度,强弱由演奏者自行决定。力度记号进入谱面,是从巴洛克时期开始的:羽管键琴不能靠触键改变音量,作曲家干脆用阶梯式的强弱切换(通称"阶梯力度"),p 与 f 整段整段地交替。
- 18 世纪中期的曼海姆乐派以乐队渐强闻名,史称"曼海姆渐强":一整支乐队从小声渐推到全奏,当时是新鲜的听觉体验。
- 贝多芬把力度变成戏剧工具:突然的 p、成片的 sfz、极端的强弱落差都是他的招牌。浪漫主义时期力度范围进一步扩展,乐谱上开始出现 ppp 与 fff 一类的极端标记。
- 奏法记号的演化也类似:断奏的点、横线在巴洛克谱面就有,但"点与横线到底差多少"的诠释争论一直延续到今天。

## 常见误区

1. 把力度当成绝对音量:p 和 f 是相对刻度,随乐器、编制、场地缩放:乐队里的"弱"和独奏长笛的"弱"完全不是一回事。
2. 断奏就是弹得越短越好:断奏的核心是"分离",音的长短要看速度与语境;快板里断奏可以并不短。
3. 把延长号当固定倍数:它并非简单的一拍变两拍,而是自由延长,长度交给乐句的呼吸和指挥的手势。
4. 只读音符、跳过表情记号:同一串音符,连奏与断奏、f 与 p 出来是两种音乐;读谱时把表情记号和音符一起读,才算读完谱。

## 名曲用例

- 海顿《第 94 交响曲"惊愕"》:开头刻意压到很弱,随后乐队一记突强的全奏——据说是为了在音乐会上惊醒打瞌睡的听众,强弱对比本身就是这首曲子的笑点。
- 拉威尔《波莱罗》:整首曲子是一次持续十几分钟的渐强,同一段旋律反复叠加乐器,音量从小声一路推到全奏,是"渐变记号"最极致的放大。
- 贝多芬的作品里到处是成片的突强与突然转弱:他的谱面证明,力度本身就是主题的一部分。
- 格里格《在山魔王的宫殿里》:旋律重复中逐渐加速、渐强,到结尾爆发,是渐强渐快叠加的标准教材。

## 练习

1. 双版本练习:把同一段 8 拍旋律在真实乐器上连奏弹一遍、断奏弹一遍,节奏保持完全一致。自查:录音对比时只有音色与音长的差别,拍点没有移动。
2. 渐强渐弱阶梯:配合上面 60 BPM 的节拍器,4 拍渐强接 4 拍渐弱,循环六遍。自查:音量变化平滑,没有台阶式的突变,拍点始终稳定。
3. 谱面侦察:拿到新谱先不弹,用笔圈出所有力度与奏法记号,说出每一句的力度级别。自查:不碰琴也能完整复述全曲的强弱布局。

> 力度与奏法记号是演奏者的"二度创作空间":谱面写 `p`,到底是多轻、轻得多圆润——正是诠释的学问。
