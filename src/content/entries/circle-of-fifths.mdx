**五度圈**(Circle of Fifths)是把 12 个调按**纯五度**关系排成一圈的"调性地图"。它是理解调号、近关系调与转调的核心工具。

## 圈的走法

从 C 出发,**顺时针每次上移纯五度**,调号里多一个升号 ♯;逆时针每次下移五度,多一个降号 ♭:

| 方向           | 顺序                      | 升降号数                   |
| -------------- | ------------------------- | -------------------------- |
| 顺时针(♯ 增加) | C → G → D → A → E → B     | 0 → 1♯ → 2♯ → 3♯ → 4♯ → 5♯ |
| 逆时针(♭ 增加) | C → F → B♭ → E♭ → A♭ → D♭ | 0 → 1♭ → 2♭ → 3♭ → 4♭ → 5♭ |

听一下连续上五度的声音(C–G–D–A),感受"越走越亮、越走越远"的感觉:

## 每个调的"邻居"

圈上**相邻**的调互为**近关系调**(共用最多音):

- G 大调是 C 的近邻(只差一个 F♯):所以 C 调的歌常借 G 调的[和弦](/entries/chord)。
- 每个大调的**关系小调**在它内侧:如 C 大调 ↔ a 小调,G 大调 ↔ e 小调。

把"相邻"量化就是严格定义:调号相差不超过一个升降号的调互为近关系调,C 大调的近关系调共五个(G、F、a、e、d),它们与 C 共用六个自然和弦,是转调最顺的目的地,详见 [近关系调](/entries/closely-related-keys)。

## 和声功能:圈上的 T–S–D 三区

圈不只是调号地图,还是**功能地图**。以 C 为中心:

- **顺时针一步(G)** 是属方向(D):比 C 多一个升号,色彩更"亮"、张力更强,天生想拉回 C;
- **逆时针一步(F)** 是下属方向(S):比 C 多一个降号,色彩更"松",常把音乐送出主和弦;
- 于是 [终止式](/entries/cadences) 的两大支柱 IV 与 V,正好是 I 在圈上的左右邻居。这不是巧合:功能和声的"出发(S)→ 紧张(D)→ 回家(T)"就是绕着 C 逆时针出去、顺时针回来。

再看**正对面**:C 的直径对面是 F♯/G♭,根音相距三全音。G7 与 D♭7 共享同一个三全音、可以互换,[三全音替代](/entries/tritone-substitution) 的几何根源就在圈上这条直径里。

## 五度圈进行:引力引擎

根音**下行纯五度**(= 圈上逆时针一步的反向读法,即沿圈连续走)是西方和声里最强的推进力。把自然[音阶](/entries/scale)内的[七和弦](/entries/seventh-chords)沿圈排成链,就是共性写作时期的"引力引擎":

**vii° → iii → vi → ii → V → I**,每一步根音都下行五度,一路被推着回家。

这条链在[流行](/entries/pop)里依然活着:[4536251](/entries/pop-progressions) 的 **3→6→2→5→1**(Em→Am→Dm→G→C)正是其中一段;[爵士](/entries/jazz)的 **ii–V–I** 是它的最后两步;《秋叶》整曲几乎走完一圈。理解了这条链,就理解了为什么这些进行"听起来 inevitable"。

## 三个实用场景

1. **记调号**:升号数 = 顺时针步数(1♯ = G,2♯ = D……);降号同理逆时针。
2. **转调**:转去隔壁的调最顺,跳得越远越"刺激"。
3. **写[和弦进行](/entries/chord-progression)**:圈上相邻调的和弦互相借用,是流行/爵士常用手法。

## 简史

- 五度关系被用来组织音律,最早可以追溯到古希腊的毕达哥拉斯学派:按弦长比例 3:2 连续生律,就能从一个音推出下一个音,五度圈就是把这条"生律链"首尾相接。
- 今天常见的圆圈图示,定型于 18 世纪的德国理论家海尼兴(Heinichen)等人之手,起初是为通奏低音实践服务的调性总览。
- 在十二平均律普及之前,圈是闭不严的:不同律制下,♯ 系与 ♭ 系的远端调音高并不完全重合。平均律让 12 步五度正好走回起点,五度圈才成为完整的一圈。

## 常见误区

1. 把"圈上相邻"当成"任意两调都接近":只有圈上挨着的调才互为近关系,隔得越远,共用的音越少,转调越突兀。
2. 升降号的方向记反:顺时针加升号、逆时针加降号;把方向弄混,调号会整行写错。
3. 只背升号数不背降号数:两个方向的规律互为镜像,顺着圈各走一遍就能同时记住,单背一侧容易漏。
4. 把圈只当成大调的圈:每个大调内侧都挂着关系小调,小调的近关系调、转调路线同样在图上。

## 名曲里的五度圈

- 《秋叶》(Autumn Leaves,约瑟夫·科斯玛作曲):全曲的和声骨架几乎沿圈走了一圈,根音按五度连续下行,是"五度圈进行"最著名的展示。
- 爵士乐最基础的 II–V–I 进行,就是沿圈连走两步再回家;标准曲里随处可见它的连环。
- 帕赫贝尔《卡农》的低音序列也大量依赖五度下行的引力,只是中间穿插了几步别的走向。

## 练习

1. 空手画圈:不看资料,在纸上默写 12 个位置的调名与升降号数,再对照标准图核对。自查:顺时针、逆时针两个方向各走一遍,全部写对。
2. 邻调快问:随机指圈上一个调,立刻说出它的左右邻居和关系小调。自查:每个调 3 秒内答出,连续 10 个不错。
3. 移调实战:把一段熟悉的简单旋律(如《小星星》)从 C 调移到 G 调再弹/唱一遍,体会调号只多一个 ♯。自查:不写谱也能哼出新调,且没有漏掉 F♯。

> 把五度圈背下来,12 个调的调号、关系、走向就全在一张图里了。
