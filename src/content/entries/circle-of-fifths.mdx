**五度圈**(Circle of Fifths)是把 12 个调按**纯五度**关系排成一圈的"调性地图"。它是理解调号、近关系调与转调的核心工具。

## 圈的走法

从 C 出发,**顺时针每次上移纯五度**,调号里多一个升号 ♯;逆时针每次下移五度,多一个降号 ♭:

| 方向 | 顺序 | 升降号数 |
| --- | --- | --- |
| 顺时针(♯ 增加) | C → G → D → A → E → B | 0 → 1♯ → 2♯ → 3♯ → 4♯ → 5♯ |
| 逆时针(♭ 增加) | C → F → B♭ → E♭ → A♭ → D♭ | 0 → 1♭ → 2♭ → 3♭ → 4♭ → 5♭ |

听一下连续上五度的声音(C–G–D–A),感受"越走越亮、越走越远"的感觉:

## 每个调的"邻居"

圈上**相邻**的调互为**近关系调**(共用最多音):

- G 大调是 C 的近邻(只差一个 F♯)——所以 C 调的歌常借 G 调的和弦。
- 每个大调的**关系小调**在它内侧:如 C 大调 ↔ a 小调,G 大调 ↔ e 小调。

## 三个实用场景

1. **记调号**:升号数 = 顺时针步数(1♯ = G,2♯ = D……);降号同理逆时针。
2. **转调**:转去隔壁的调最顺,跳得越远越"刺激"。
3. **写和弦进行**:圈上相邻调的和弦互相借用,是流行/爵士常用手法。

> 把五度圈背下来,12 个调的调号、关系、走向就全在一张图里了。
