**和弦反查**是一类「给音求名」的工具:你给它一组音,它告诉你这组音是什么[和弦](/entries/chord)。最常见的场景是拿着吉他扒歌——听到一个按法,在指板上点出来,名字立刻揭晓;反过来,自学时按完一个和弦,用它验证自己按的音到底对不对。

## 怎么用

在下面指板上点出你按住的格子(空弦点 0 品),答案实时更新;再点一次取消选中:

<ChordFinder
  client:visible
  label="和弦反查:点出你按的格子(空弦点 0 品),答案实时更新;候选和弦可试听。"
/>

已选的音以小标签列在答案区下方,点单个标签可以移除;「试听」会把你选的音从低到高逐个弹响。答案分三种话术:是某个和弦、差一点是某个和弦(缺音)、某个和弦加音——分别对应精确、缺音、加音三种匹配结果。

## 它是怎么认出来的

核心是一层很朴素的原理:音级集合。

- 忽略八度:C4 与 C3 都记作音级 C,同一和弦不同把位的答案因此一致;
- 与和弦库逐一比对:库里每个和弦都有音级集合,你的集合与哪个对上,就是哪个;
- 允许不完全相等:差一个音的排在其后,差得越多越靠后——所以答案区第一名永远是「最像」的那个。

工具替你算,不替你听。听出色彩、记住音响,是[视唱练耳](/entries/pitch-training)的事;反查负责把「手指知道的东西」翻译成「嘴能说出的名字」。

## 同一组音,两个名字

试一个实验:先点出 Dsus2(x x 0 2 3 0),答案是 Dsus2;清空后点出 Asus4(x 0 2 2 3 0),答案是 Asus4。两组音级一模一样,都是 A、D、E。

这不是 bug。挂留和弦的构造决定了这种巧合:拿掉三音、换上二度或四度之后,挂留和弦常常与另一个根音的挂留和弦共用全部音级(Asus2 与 Esus4 也是一对,都是 A、B、E)。此时和弦名由「谁是根音」决定,而根音要看按法与语境——工具的做法是:格子与哪个标准按法完全一致,首选就给哪个;两个都点不一致,就两个都列出来,让你用耳朵与上下文定夺。构造细节见[挂留与加音和弦](/entries/suspended-and-added)。

## 什么时候用得上

- 扒歌:听到怪按法,在指板上摸出来点一下,名字揭晓,再去查这个和弦的用法;
- 验证:自学[开放和弦](/entries/guitar-open-chords)时按完点一下,缺音、错音立刻现形——少按一根弦是「差一点」,多按一根可能已经变成另一个和弦;
- 找色彩:编曲时想要更空灵或更悬置的声响,在基本和弦上试着加音、换音,反查帮你确认「现在这手到底是什么和弦」,名字对了,乐理书里关于它的用法才查得到。

## 常见误区

1. 拿反查替代耳朵。工具给出集合视角的候选,最终定名要看调性语境:同一组音在不同调里可以有不同身份。先听,再查,名字才长在耳朵上。
2. 以为答案必须唯一。同名异构、异名同音在和弦世界是常态而非例外,「唯一正确答案」的期待本身要放下——候选列表正是为此设计。
3. 点亮的格子与实际弹奏不一致。闷掉的弦不发声,反查里就不要点它;点了,答案就对不上你听到的音响,自查练习时尤其容易在这里迷惑。

## 练习

1. 验证 C:点出 C 的标准按位(x 3 2 0 1 0),看答案是「C——标准按法」。自查:五个格子一次点对,答案区不需要看次候选。
2. 同音异名实验:先点 Dsus2(x x 0 2 3 0),再改成 Asus4(x 0 2 2 3 0),观察首选如何切换。自查:两个按法答案区都只差「按法」二字——首选都标注了标准按法。
3. 造一个加音和弦:在 C(x 3 2 0 1 0)基础上,把 2 弦从 1 品改按 3 品(C 换成 D),答案变成 Cadd9。自查:答案区话术是「C 加音」,次候选里不再出现普通的 C。
