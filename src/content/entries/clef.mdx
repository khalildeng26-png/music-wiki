谱号(clef)写在每行[五线谱](/entries/staff-notation)的开头,作用是**给五条线赋予具体的音高含义**。没有谱号,线上的位置就无法对应到具体的音。

## 常见谱号

- **高音谱号(G 谱号) 𝄞**:第二线 = G。常用于女声、[小提琴](/entries/violin)、右手[钢琴](/entries/piano)等较高音区。
- **低音谱号(F 谱号) 𝄢**:第四线 = F。常用于男声低音、大提琴、左手钢琴等较低音区。
- **中音谱号(C 谱号) 𝄡**:中央 C 在谱号指针指向的那条线上。常见于中提琴。

## 大谱表

高音谱号与低音谱号上下叠在一起,用花括号连起来,就叫**大谱表**(grand staff),钢琴谱多用此形式。

## 谱号的简史

- 谱号这个词来自法语,本义是"钥匙":它打开的是五线谱的意义:没有它,五条线只是五条线。
- 最早的记谱并不画谱号,而是在行首直接写字母:在一条线的开头写 F 或 C,表示这条线是什么音。后来手写的字母越写越花,逐渐符号化,才成了今天的 𝄞、𝄢、𝄡。
- 高音谱号是字母 G 的变体,旋涡圈住的那条线就是 G;低音谱号是字母 F 的变体,两个点夹住的线就是 F;中音谱号保留了 C 的形状,指针(两个反向弧的交汇)指向哪条线,哪条线就是中央 C。
- 五线谱的行数也经历过演变,早期常见四线谱,六线谱也出现过;今天通用的五线定型之后,谱号的"定锚"作用就更加关键。

## 谁用什么谱号

- 高音谱号:小提琴、[长笛](/entries/flute)、[双簧管](/entries/oboe)、[小号](/entries/trumpet)、女高音声部、钢琴右手;
- 低音谱号:大提琴、[大管](/entries/bassoon)、[长号](/entries/trombone)、[大号](/entries/tuba)、男低音声部、钢琴左手;
- 中音谱号:中提琴的固定谱号;历史上也用于人声的中音声部;
- 次中音谱号(指针在第四线的 C 谱号):大提琴、大管、长号在较高音区时使用,为的是少加线。

规律只有一条:哪种谱号让音尽量落在五条线以内、少加线,就用哪种。

## 常见误区

1. 换了谱号还用旧位置读:同一条线在高音谱号里是 G,在低音谱号里是 B。读谱前先看谱号,位置的意义完全不同。
2. 以为低音谱号就是高音谱号"整体往下移":两个谱号各自定锚,没有平移关系;中央 C 在高音谱号是下加一线,在低音谱号是上加一线。
3. 中音谱号找错中线:C 谱号的两个弧交汇在指针尖端,中音谱号里这个尖正好压在第三线上;数错一行,整段读错。
4. 忽略行中的换谱号标记:谱号可以在曲中更换,从更换处起按新谱号读;扫谱时先找所有谱号,再读音符。

## 练习

1. 定锚快答:给任意谱号,3 秒内说出它标定的那条线是什么音。自查:高音谱号(G)、低音谱号(F)、中音谱号(中央 C)三个答案连续答对 10 次。
2. 中央 C 追踪:翻开一份大谱表的钢琴谱,找出所有中央 C 的位置,确认它们都贴着两行谱的交界处。自查:每处中央 C 都能一眼认出,不需要数线。
3. 双谱号对照:把同一条简单旋律(如《小星星》前句)分别用高音谱号与低音谱号读一遍,换谱号前先说出新的定锚音。自查:两遍读音一致,换谱号处不出错。

> 读谱先看谱号,再读音高。
