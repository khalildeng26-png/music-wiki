**和弦标记**(chord symbols)是[流行音乐](/entries/pop)谱面(歌词谱、[吉他](/entries/guitar)谱)上最常见的记法:在歌词或旋律上方直接标出和弦名,演奏者据此即兴伴奏。看懂它,一张"歌词+和弦"的谱就能弹起来。

## 基本构成

一个和弦标记 = **根音字母 + 性质后缀**,如 `Am7` = 以 A 为根音的小七和弦。根音用大写字母 C D E F G A B,升降号用 ♯/♭(或 #/b)。

## 常用后缀速查

| 标记           | 含义                   | 例:以 C 为根音 |
| -------------- | ---------------------- | -------------- |
| `C`            | 大三和弦               | C–E–G          |
| `Cm` 或 `C-`   | 小三和弦               | C–E♭–G         |
| `Cdim` 或 `C°` | 减三和弦               | C–E♭–G♭        |
| `Caug` 或 `C+` | 增三和弦               | C–E–G♯         |
| `C7`           | 属七和弦               | C–E–G–B♭       |
| `Cmaj7`        | 大七和弦               | C–E–G–B        |
| `Cm7`          | 小七和弦               | C–E♭–G–B♭      |
| `Csus4`        | 挂四和弦(三音换成四音) | C–F–G          |

## 斜杠和弦(转位标记)

`C/E` 读作"C on E":弹 **C 和弦**,但**最低音([贝斯](/entries/bass))要落在 E 上**:即 C 和弦的第一转位。流行歌的贝斯线条常靠它走顺(如 C → C/B → Am)。

> 记忆口诀:斜杠左边是"弹什么",右边是"低音弹什么"。

## 和弦标记 vs 五线谱

和弦标记**不规定具体排列和节奏型**,把发挥空间留给演奏者,这正是它适合伴奏/即兴的原因;需要精确控制每个音时,还是看 [五线谱](/entries/staff-notation)。

## 简史

- 数字低音(17 世纪起的通奏低音)是最早的"符号和声":作曲家只写低音声部,在它下方标数字,表示上方该叠出什么和弦;键盘手据此即兴填充,和声交给演奏者的传统由此开始。
- 20 世纪初,锡盘巷与百老汇的出版歌曲需要让家庭[钢琴](/entries/piano)和业余乐手快速上手,歌词上方直接印和弦名的记法逐渐普及。
- 1940 年代起的[爵士乐](/entries/jazz)让这套记法彻底标准化:乐手靠 lead sheet 即兴,和弦标记必须跨乐器、跨乐队通用,于是出现了今天这套根音字母加后缀的写法,吉他谱、弹唱谱、Real Book 全部沿用。

## 常见误区

1. `C7` 读成"C 大七":后缀里没有 maj 的"7"就是属七:大三和弦加小七度,音是 C–E–G–B♭,不是 C–E–G–B。
2. `F/G` 当成 F 和 G 两个和弦轮流弹:它只表示一个和弦:弹 F 和弦,最低音用 G。
3. 见到 `m7` 就弹成小三和弦:m7 是四个音的小七和弦(Cm7 = C–E♭–G–B♭),比 Cm 多一个七度音,色彩也随之变化。
4. 用字母大小写判断和弦性质:根音字母永远大写,性质只看后缀:Am、A7、Amaj7 的根音都是 A,别在字母上找线索。

## 名曲用例

- 《生日快乐》的吉他谱通常只有三四个和弦标记(如 C、F、G),是弹唱入门的标准教材。
- 格什温《I Got Rhythm》的和声骨架被爵士乐手反复借用,衍生出的 rhythm changes 在 Real Book 里大量出现,它的 lead sheet 就是典型的"旋律+和弦标记"记法。
- 披头士《Let It Be》:主歌四个和弦的循环,是弹唱课上最常见的第一份和弦谱。

## 练习

1. 后缀闪卡:随机写出 10 个和弦标记,先在脑中拼出组成音,再在键盘或组件上验证。自查:10 个里至少 8 个一次拼对。
2. 斜杠和弦找低音:给 5 个斜杠和弦(如 C/E、G/B、D/F♯),只弹最低音组成的线条,听它是不是连贯的下行或上行。自查:低音线一步接一步,没有跳。
3. 看谱即弹:找一份简单的弹唱谱,跟着和弦标记给一段旋律伴奏,右手按和弦、左手走根音。自查:中途不停顿地跟完一句,换和弦的时机准确。
