    a: 每个和弦弹它的根音和上方纯五度两个音(如 C 弹 C–G),轮流或交替。从乡村到摇滚通用的贝斯基本功型,比纯根音更有推动力。

  - q: 四弦贝斯的音域有多宽?
    a: 标准定弦从低到高是 E1、A1、D2、G2;加上品位,常见琴的音域覆盖三个八度上下,应付绝大多数流行歌曲足够。

只会根音,音够用但歌显得"平"。这一步给耳朵添两种味道:完整的 [音阶](/entries/scale),和最经典的两人组——**根音-五度**。

## C 大调音阶:开放把位

贝斯上最顺手的入门音阶,全在 0–5 品内:

| 音  | 位置              |
| --- | ----------------- |
| C2  | 3 弦(A 弦)第 3 品 |
| D2  | 2 弦空弦          |
| E2  | 2 弦第 2 品       |
| F2  | 2 弦第 3 品       |
| G2  | 1 弦空弦          |
| A2  | 1 弦第 2 品       |
| B2  | 1 弦第 4 品       |
| C3  | 1 弦第 5 品       |

## 根音-五度:伴奏神器

每个和弦除了根音,再加上**上方纯五度**:

- C 和弦 → **C + G**
- F 和弦 → **F + C**
- G 和弦 → **G + D**

弹法通常是根音、五度交替(一小节 C G C G)。听感立刻从"报幕"变成"走路"——这是乡村、民谣、摇滚通用的基本功型:

> 五度为什么这么百搭?因为它是泛音列里紧随八度之后的音(见 [泛音列](/entries/overtone-series)),跟谁都不打架。贝斯手的"安全牌"就是它。

## 名曲用例

- 根音-五度交替是乡村音乐的招牌低音:经典"boom-chick"节奏里来回走的那两个低音,就是根音和五度。
- 早期摇滚乐大量继承这种走法,许多歌曲的 bassline 就是根音-五度换一身节奏出现。听的时候盯住低音,很容易认出这个形状:走慢走疏,它是乡村;走快走密,它又是摇滚。

## 常见误区

1. 只练上行:音阶走到顶立刻原路下行,一口气走完。返回的路单独不熟,问题都出在上行结束那一刻。
2. 左手缩成一团:根音用食指,五度用无名指或小指撑出去,手架打开、手腕放松,两音交替时手不要来回挪。
3. 把音阶当速度练习:先在节拍器 60 BPM 下一拍一音走稳,每个音都实,再谈加速。

## 练习

1. 一拍一音:节拍器 60 BPM,音阶上下行一个八度,右手食指中指交替。自查:音量均匀,换向不停顿。
2. 一拍两音:同一速度下改成八分音符,指法不变。自查:还能清楚听出每个音落在拍点上。
3. 根音-五度替换:按 C G C G、F C F C、G D G D 的顺序各弹一小节,80 BPM。自查:五度音准、无杂音,四拍不断。

最后一步:把根音、五度、经过音拼成一条完整的 bassline——你的第一条。
