翻开 [总谱](/entries/score-reading) 或管乐分谱,你会看到乐器名后面跟着 **in B♭**、**in F** 这样的标记,这是**移调乐器**(transposing instruments):**谱上写的音高 ≠ 实际发出的音高**。谱面写 C,B♭ 单簧管发出的是 B♭。

## 为什么要这么设计

不是故意刁难人,而是**指法统一**:

- 单簧管、萨克斯这类"家族乐器"有大有小,若每件都按实际音高记谱,乐手换一件就要换一套指法;
- 统一成"指法不变、谱面随乐器移",乐手学一次指法就能吹全家族;
- 圆号的移调另有来历:自然号时代没有活塞,只能吹泛音列,记谱方式由此定型并沿用至今。

乐器名里的 **in B♭** 指**这件乐器的基础音是 B♭**:用 C 指法(乐器最自然的指法)吹出来的就是 B♭。

## 常见移调乐器速查

| 乐器                      | 调     | 谱上写 C,实际发 | 差距                  |
| ------------------------- | ------ | --------------- | --------------------- |
| 短笛                      | C      | 高八度的 C      | 高八度                |
| **单簧管 / 小号**         | **B♭** | **B♭**          | **低大二度**          |
| 单簧管                    | A      | A               | 低小三度              |
| 圆号                      | F      | F               | 低纯五度              |
| 中音 / 上低音萨克斯       | E♭     | E♭              | 低大六度              |
| 次中音萨克斯 / 低音单簧管 | B♭     | B♭              | 低大九度(八度+大二度) |
| 吉他 / 低音提琴           | —      | 低八度          | 低八度                |

## 谁需要会换算

- **指挥 / 编曲**:总谱里要"移读":看单簧管行时脑内上移大二度才是实音;写作时反向移好;
- **钢琴 / 吉他伴奏者**:给 B♭ 或 E♭ 乐器伴谱,要移调配;
- **乐手本人**:反而最省心:按谱吹,指法天然对。

## 常见误区

1. 以为移调乐器的乐手要当场换算。恰恰相反:移调记谱就是为他们设计的,照谱吹,指法与实音自动对上。真正要做换算的是指挥、编曲与伴奏。
2. 把 in B♭ 理解成"这件乐器只能吹 B♭ 调"。in B♭ 只说明基础音与记谱的对应关系,十二个半音都能吹,只是全体比记谱低一个大二度。
3. 八度移调与调移混淆。吉他、低音提琴的"实音低八度"属于八度移调,谱号旁常标小 8;它不改变调,和单簧管式的整体移调是两回事。
4. 拿钢琴弹管乐分谱,发现"对不上"就断定写错了。总谱里单簧管行单独弹来总比别的乐器高一个全音,这是移调差,不是错谱。

## 名曲用例

- 莫扎特《单簧管协奏曲》(K.622):为 A 调单簧管而作。A 调单簧管实音比记谱低小三度,全曲要在 A 大调上响起,单簧管声部便记成 C 大调指法,是"记谱迁就指法"的著名案例。
- 交响乐总谱里的圆号声部惯常记作 in F,浪漫时期以来的总谱尤其如此:遇到圆号行整体下移纯五度,才是乐队里实际响起的音高。
- 管乐团里的萨克斯声部整组都带移调标记:中音萨克斯 in E♭、次中音 in B♭,编曲时要逐一换算,是管乐配器的日常功课。

## 试一试

换算练习先练耳朵:先听上面"乐手看到的"一组,再听"实际听到的"一组,判断两组之间的音程差。两组反复交替听,直到能脱口说出"大二度""纯五度"。

## 练习

1. 双向换算:任写一条 5 音旋律,写出它的降 B 单簧管谱(移高大二度),再反过来从单簧管谱还原实音(移低大二度)。自查:连续 5 条双向无误。
2. 总谱移读:找一段带单簧管行的总谱,先照谱面唱一遍,再移低大二度唱一遍,对照录音。自查:不看标记也能说出该行实音与谱面的差距。
3. 标记速认:遮住速查表,给五种乐器(单簧管、小号、圆号、中音萨克斯、吉他)逐一报出移调方向与音程。自查:每种 3 秒内答对。

> 移调记谱为演奏者省事,为读谱者添堵;认得 in B♭ / in F 这些标记,总谱里"听起来不对"的行就不会困扰你。
