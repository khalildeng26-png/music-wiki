翻开 [总谱](/entries/score-reading) 或管乐分谱,你会看到乐器名后面跟着 **in B♭**、**in F** 这样的标记——这是**移调乐器**(transposing instruments):**谱上写的音高 ≠ 实际发出的音高**。谱面写 C,B♭ 单簧管发出的是 B♭。

## 为什么要这么设计

不是故意刁难人,而是**指法统一**:

- 单簧管、萨克斯这类"家族乐器"有大有小,若每件都按实际音高记谱,乐手换一件就要换一套指法;
- 统一成"指法不变、谱面随乐器移",乐手学一次指法就能吹全家族;
- 圆号的移调另有来历:自然号时代没有活塞,只能吹泛音列,记谱方式由此定型并沿用至今。

乐器名里的 **in B♭** 指**这件乐器的基础音是 B♭**——用 C 指法(乐器最自然的指法)吹出来的就是 B♭。

## 常见移调乐器速查

| 乐器                      | 调     | 谱上写 C,实际发 | 差距                  |
| ------------------------- | ------ | --------------- | --------------------- |
| 短笛                      | C      | 高八度的 C      | 高八度                |
| **单簧管 / 小号**         | **B♭** | **B♭**          | **低大二度**          |
| 单簧管                    | A      | A               | 低小三度              |
| 圆号                      | F      | F               | 低纯五度              |
| 中音 / 上低音萨克斯       | E♭     | E♭              | 低大六度              |
| 次中音萨克斯 / 低音单簧管 | B♭     | B♭              | 低大九度(八度+大二度) |
| 吉他 / 低音提琴           | —      | 低八度          | 低八度                |

## 谁需要会换算

- **指挥 / 编曲**:总谱里要"移读"——看单簧管行时脑内上移大二度才是实音;写作时反向移好;
- **钢琴 / 吉他伴奏者**:给 B♭ 或 E♭ 乐器伴谱,要移调配;
- **乐手本人**:反而最省心——按谱吹,指法天然对。

移调的具体手法(音程平移、调号换算)见乐理侧的 [移调](/entries/transposition);乐器家族的详细成员见 [单簧管](/entries/clarinet) 与 [管弦乐队](/entries/orchestra)。

> 一句话:**移调记谱是为演奏者省事,为读谱者添堵**——认得 in B♭ / in F 这些标记,你在总谱里就不会被"听起来不对"的行搞糊涂。
