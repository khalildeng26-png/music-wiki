在五线谱里,**音符长什么样,就唱多长**。时值体系是一套干净的"对半分"系统(以 4/4 拍为例):

## 时值家族

| 音符         | 形状特征          | 时值(4/4) |
| ------------ | ----------------- | --------- |
| 全音符       | 空心符头,无符干   | 4 拍      |
| 二分音符     | 空心符头 + 符干   | 2 拍      |
| 四分音符     | 实心符头 + 符干   | 1 拍      |
| 八分音符     | 实心 + 1 条符尾   | 半拍      |
| 十六分音符   | 实心 + 2 条符尾   | 1/4 拍    |
| 三十二分音符 | 实心 + 3 条符尾   | 1/8 拍    |

规律:**每加一条符尾,时值减半**;空心变实心,也是减半。休止符(休息)有完全对应的另一套形状。

## 符杠:符尾的合并写法

八分音符及更短的音符通常不单独画符尾,而是用**符杠**(横梁)连起来:两个八分音符共用一条杠,四个十六分音符共用两条杠。符杠按拍分组:4/4 拍里,同一拍内的音符杠在一起。读谱时只需记住:一条杠 = 八分音符,两条杠 = 十六分音符。

## 附点、连线与圆滑线

- **附点**(.):写在音符后,表示**再加该音符一半的时值**:附点二分音符 = 2 + 1 = 3 拍。双附点再加一半的一半(2 + 1 + 0.5 = 3.5 拍),浪漫派钢琴曲里常见。
- **三连音**:减半王国里的非二等分,把一个音符均分成三份(一拍分三个八分三连音,谱上标「3」),摇摆感的原料,详见 [切分音与摇摆节奏](/entries/syncopation)。
- **连线**(tie):把两个相同音高的音连成一个长音,时值相加。它专门用来表达跨小节、或符尾无法表示的时长。
- **圆滑线**(slur):弧线和连线长得一样,但表示连贯地演奏(弦乐一弓、管乐一气、声乐一句),**不延长时值**。跨过相同音高的两个音才算连线。把圆滑线读成连线,是最常见的读谱事故。

## 与拍号的关系

"全音符 = 4 拍"这个说法**只在 4/4 拍里成立**。时值是相对的:四分音符永远是"一拍"的那个单位,一拍有多长则由 [拍号](/entries/rhythm-and-time-signature) 决定。2/2 拍里全音符只占 2 拍;3/4 拍里通常根本写不下一个全音符。所以"全音符长什么样"和"它占几拍",是两个要分开记的问题。

## 时值简史

今天的音符形状,是几百年演化的结果:

- 中世纪欧洲的纽姆记谱只标旋律走向,不标长短。约 1260 年,科隆的弗朗科在《有量歌曲艺术》里确立规则:**音符的形状本身决定时值**:"看形状知长短"从此开始。
- 今天"全音符"的祖先 semibrevis,在中世纪拉丁语里原意是"次短"音符,因为当时它确实比通用的长音符、短音符都短。后来音乐越写越快,更新的短音符不断加入,老音符的相对地位一路"膨胀"。时值名称永远是相对概念。
- 拍号里的 **C 和 ¢** 来自中世纪的圆圈与半圆:圆圈表示"三等分"(当时认为三最完美),半圆表示"二等分"。4/4 拍至今仍记作 C,2/2 拍记作 ¢。
- 1815 年梅尔策尔取得节拍器专利,贝多芬是最早在乐谱上标注节拍器速度的作曲家之一,时值从此可以用秒来精确校验。英国人至今仍用古名称呼音符:semibreve(全)、minim(二分)、crotchet(四分)、quaver(八分)。

## 常见误读

1. **附点 = 加一拍**:错。附点加的是本音符的一半。附点二分音符是 3 拍,因为 2 + 1,不是因为有"加一拍"这条规则。
2. **把"全音符 = 4 拍"当绝对**:见上一节,它只是 4/4 拍里的相对关系。
3. **连线跨小节时重新起音**:连线本来就是为了跨小节存在的,见到连线就保持住音,不要进下一小节时重新弹。
4. **背成固定秒数**:时值是比例:四分音符永远等于两个八分音符,无论速度快慢。

## 名曲里的时值

- 《小星星》:基本全是四分音符,每句结尾("star"、"high"处)是一个二分音符长音,是"四分 = 走、二分 = 走-停"的经典入门例。莫扎特还为这首法国民歌写过十二段变奏(K.265)。
- 贝多芬《欢乐颂》(第九交响曲末乐章):前两句全是四分音符,第四句出现**附点四分 + 八分**:零基础接触附点节奏的标准例子。
- 《玛丽有只小羊羔》:四分与二分混合("lamb"处是二分),适合在《小星星》之后练。

## 练习

1. **细分金字塔**:节拍器 60 BPM,一拍打一下 → 两下 → 四下,再倒回来。要求十六分的四个音严格均匀。自查:连续三遍速度不波动、不赶拍。
2. **附点反转练法**:把"附点八分 + 十六分"的节奏反过来练成"十六分 + 附点八分",交替进行。自查:短的那个十六分必须落在拍点前的最后一个细分位,而不是拍点正中间。
3. **录音对照**:念或弹一段四分、八分、十六分混合的节奏并录音,回放检查。自查:每个音都压在细分点上,后半段没有越赶越快。

> 时值的本质是**比例**而不是绝对时间:无论速度快慢,四分音符永远等于两个八分音符。
