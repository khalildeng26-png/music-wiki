**声部**(voice type)是按**音域**(能唱的最低音到最高音)和**音色**对人声的分类。古典声乐用它分配角色;流行演唱中,了解声部则帮你**选歌、定调**。

## 六大基本声部

| 声部 | 音域(约) | 音色特点 |
| --- | --- | --- |
| **女高音(Soprano)** | 中央 C 以上两个八度 | 明亮、纤细,常唱主旋律 |
| **女中音(Mezzo)** | 比女高略低 | 醇厚、温暖 |
| **女低音(Contralto)** | 女声最低 | 深沉、少见而珍贵 |
| **男高音(Tenor)** | 男声最高(高一个八度记谱) | 明亮有穿透力,流行主唱常见 |
| **男中音(Baritone)** | 男声中间 | 厚实、磁性,最常见 |
| **男低音(Bass)** | 男声最低 | 浑厚、低沉 |

## 怎么判断自己的声部

- 最实用的方法:在钢琴/键盘上试,找到自己**能舒服唱出的最低音和最高音**,再看这个范围落在哪个声部。
- 注意:未经训练的人可用音域偏窄,**训练会拓宽两头**(尤其高音靠 [混声](/entries/vocal-registers) 打开)。
- 流行里不必死抠声部标签——更重要的是知道自己**舒适的换声点和最佳表现音区**。

> 声部不是限制,是地图:知道自己是什么声部,就知道该练哪段、该避开哪段。
