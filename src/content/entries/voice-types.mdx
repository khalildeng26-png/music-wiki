**声部**(voice type)是按**音域**(能唱的最低音到最高音)和**音色**对人声的分类。[古典](/entries/classical)声乐用它分配角色;[流行](/entries/pop)演唱中,了解声部则帮你**选歌、定调**。

## 六大基本声部

| 声部                  | 音域(约)                 | 音色特点                  |
| --------------------- | ------------------------ | ------------------------- |
| **女高音(Soprano)**   | 中央 C 以上两个八度      | 明亮、纤细,常唱主旋律     |
| **女中音(Mezzo)**     | 比女高略低               | 醇厚、温暖                |
| **女低音(Contralto)** | 女声最低                 | 深沉、少见而珍贵          |
| **男高音(Tenor)**     | 男声最高(高一个八度记谱) | 明亮有穿透力,流行主唱常见 |
| **男中音(Baritone)**  | 男声中间                 | 厚实、磁性,最常见         |
| **男低音(Bass)**      | 男声最低                 | 浑厚、低沉                |

## 怎么判断自己的声部

- 最实用的方法:在[钢琴](/entries/piano)/键盘上试,找到自己**能舒服唱出的最低音和最高音**,再看这个范围落在哪个声部。
- 注意:未经训练的人可用音域偏窄,**训练会拓宽两头**(尤其高音靠 [混声](/entries/vocal-registers) 打开)。
- 流行里不必死抠声部标签:更重要的是知道自己**舒适的换声点和最佳表现音区**。

## 常见误区

1. 声部分高低贵贱。声部只描述音色与音域,没有优劣:男高音抢耳,男中音厚实磁性,男低音的沉稳同样无可替代。硬往"更高"的声部挤,是伤嗓子的开始。
2. 只按音域定声部。声部要音域与音色合看:同样能唱到某个高音的两个人,一个音色厚实,一个明亮轻盈,归属的声部就不同。
3. 测一次管终身。未经训练时可用音域偏窄,训练会向两头拓宽。今天测出的范围,练半年后再测,上下都可能宽出一截。
4. 用蛮力顶高音。高音的打开靠混声,加大音量硬挤,出来的声音又紧又扁,嗓子也跟着受罪。换声点附近的办法,见 [真假声与混声](/entries/vocal-registers)。

## 歌剧舞台上的声部

古典歌剧按声部分角色,看歌剧前先认声部,大体不会错:

- 女主角多由女高音担纲;莫扎特《魔笛》里的夜后,以一段段极高的花腔闻名。
- 比才《卡门》的主角是女中音的经典角色:醇厚、带暗色的音色,正好贴合人物性格。
- 男主角常交给男高音,英雄式的高音段落留给他。
- 男低音常演长辈、祭司一类角色,沉稳的音色自带分量。

流行演唱没有这套分配,道理却相通:歌要贴着音色挑,再谈音高。

## 练习

1. 音域建档:用上面的键盘,从舒服处往下唱到最低能发声的音,再往上唱到最高能稳定保持的音,两个音名都记下来。自查:最高音能稳住 3 秒、喉咙不发紧。
2. 常用音区摸底:挑两首喜欢的歌各唱一遍并录音,记下副歌大多落在哪个音区。自查:副歌大半落在能边唱边正常说话的音区,说明歌和嗓子大体相配。
3. 换声点定位:从低到高慢慢唱[音阶](/entries/scale),记下"再往上就得换一种唱法"的位置;隔两天再测一遍。自查:两次结果相差不超过一个半音,就可以把它当你的换声点,之后练混声都用得上。

> 声部不是限制,是地图:知道自己是什么声部,就知道该练哪段、该避开哪段。
